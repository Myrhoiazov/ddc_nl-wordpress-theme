## 2. Цель страницы

Основная конверсия:

`Посетитель → интерес → доверие → выбор тарифа → заявка → предоплата €450`

Страница должна продавать не просто поездку, а опыт:

**море → танцы → друзья → digital detox → самостоятельность → яркие
воспоминания.**

Основной посыл родителям:

> 10 дней, после которых ребёнок возвращается увереннее, самостоятельнее
> и счастливее.

## 3. Позиционирование

LITO DANCE CAMP должен восприниматься как самостоятельный summer-event
внутри экосистемы Talent Centre DDC.

Рекомендуемая архитектура бренда:

**Talent Centre DDC presents → LITO DANCE CAMP**

Страница `/camp/` визуально должна отличаться от стандартных страниц DDC
и создавать отдельный яркий мир лагеря.

Breakpoints:

``` text
< 576px     mobile
576–991px   tablet

```

-   крупная типографика;
