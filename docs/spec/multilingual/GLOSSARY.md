## Известное расхождение (зафиксировано, не исправляется в рамках этой сессии)

`CONTEXT.md` явно требует избегать «Branch» / «Филиал» как обозначения **Location** — канонический термин «Локация» / «Location» / «Locatie» / «Локація».

Однако `templates/agreement-template.php` (калькулятор цен, добавлен до формализации глоссария; раздел с Ukrainian добавлен в этой сессии по образцу уже существующих EN/NL/RU) последовательно использует терминологию **«Branch» / «Filiaal» / «Филиал» / «Філія»** (`agr-branch-*` id, подписи «Branch» / «Vestiging» / «Филиал» / «Філія»). Это осознанно не переписывалось задним числом в этой сессии, чтобы не трогать уже выверенный и синхронизированный между 4 языками калькулятор без отдельного запроса — Agreement-страница в любом случае живёт на своём отдельном мультиязычном паттерне (ADR 0001) и не обязана дословно повторять терминологию остального сайта. Если этот разнобой не устраивает — стоит унифицировать отдельной точечной правкой (переименовать «Branch/Filiaal/Филиал/Філія» → «Location/Locatie/Локация/Локація» во всех 4 языковых блоках калькулятора разом), а не как побочный эффект другой задачи.
