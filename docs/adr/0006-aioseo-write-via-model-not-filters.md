# AI-Draft SEO Fields Are Written Through AIOSEO's Post Model, Not Its Render Filters

The AI Черновики module needs the SEO title, meta description, focus keyword, and Open Graph/Twitter tags it generates to show up correctly in the AIOSEO admin editor, not just on the rendered front end. The theme already uses `aioseo_title`/`aioseo_description` filters elsewhere (e.g. the `camp` page), but those only run at front-end render time and never touch AIOSEO's stored data — a value set that way stays invisible in AIOSEO's own edit screen. AI Drafts instead write SEO fields through AIOSEO's canonical write path, `AIOSEO\Plugin\Common\Models\Post::savePost($postId, [...])`, the same method AIOSEO's own admin UI uses to save, so generated values appear correctly in both `wp_aioseo_posts` and the AIOSEO editor.
