# No national flags in the language switcher

The language switcher represents Russian and Ukrainian alongside Dutch and English. We chose text autonyms (Nederlands / Русский / Українська / English) instead of flag icons for every language, rather than the more common flag-icon switcher pattern. Pairing a language with a national flag is especially fraught for Russian and Ukrainian given the current geopolitical context, and the switcher shouldn't put a country symbol next to a language choice for this audience.

**Consequences**: don't add flag icons later as a "visual polish" pass without revisiting this reasoning first.
